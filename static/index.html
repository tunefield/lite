Rekordbox bridge — one-time setup

Field keeps all exported playlists in one XML file that Rekordbox watches. Point Rekordbox at it once — every later export then just appears in the sidebar.

~/Music/Field/tunefield.xml
  1. Rekordbox → Preferences → Advanced → Database — under “rekordbox xml”, set Imported Library to the file above (paste the path in the file dialog with ⌘⇧G).
  2. Preferences → View → Layout — tick “rekordbox xml” so the tree shows in the sidebar.
  3. In the sidebar’s rekordbox xml tree: click refresh, open the playlist, right-click → Import Playlist.

Safe: Rekordbox only reads this file — your collection database is never touched by the bridge.
